# 국비학원 자체 웹 구축 기획서 초안

작성일: 2026-05-21

## ◆ 문서 목적

본 문서는 국비지원 학원 자체 웹사이트 구축을 위해 필요한 메뉴, 기능, 운영 흐름을 정리한 기획 초안이다.

디자인 시안이나 화면 목업을 먼저 만드는 방식이 아니라, 웹사이트에 어떤 기능이 들어가고 각 기능이 어떤 역할을 하는지 먼저 확정하는 것을 목적으로 한다.

## ◆ 구축 목표

◇ 학원에서 운영하는 교육 과정을 자체 웹사이트에서 안내한다.

◇ 사용자가 과정 정보를 확인하고 온라인으로 수강 신청할 수 있게 한다.

◇ 관리자가 과정, 회차, 신청자, 공지, 문의, 회원 정보를 직접 관리할 수 있게 한다.

◇ 외부 플랫폼에 의존하지 않고 학원 내부에서 웹사이트 내용을 수정할 수 있는 구조를 만든다.

## ◆ 구축 범위

### ● 사용자 웹

○ 메인 화면

   - 대표 배너, 주요 과정, 공지사항, 문의 진입 영역을 제공한다.

○ 과정 목록

   - 모집 중이거나 운영 중인 과정을 목록으로 보여준다.

○ 과정 상세

   - 과정 소개, 교육 기간, 교육 시간, 정원, 회차 정보를 보여준다.

○ 수강 신청

   - 신청자가 기본 정보와 지원 내용을 입력하고 제출한다.

○ 공지사항

   - 학원 공지, 개강 안내, 운영 안내 등을 확인한다.

○ 문의하기

   - 사용자가 상담 또는 문의 내용을 등록한다.

### ● 관리자 웹

○ 관리자 대시보드

   - 주요 운영 현황을 요약해서 확인한다.

○ 과정 관리

   - 과정 목록을 조회하고 과정을 등록, 수정, 삭제한다.

○ 회차 관리

   - 과정별 기수, 교육 기간, 시간, 정원, 모집 상태를 관리한다.

○ 신청자 관리

   - 과정 회차별 신청자를 확인하고 처리 상태를 관리한다.

○ 공지사항 관리

   - 공지를 등록, 수정, 삭제하고 노출 여부를 관리한다.

○ 문의사항 관리

   - 문의 목록을 확인하고 답변과 처리 상태를 관리한다.

○ 회원 관리

   - 회원 목록, 회원 상세 정보, 수강 기록을 확인한다.

○ 비밀번호 변경

   - 관리자 권한으로 계정 비밀번호를 초기화하거나 변경한다.

### ● 서버 및 데이터

   - 로그인, 회원가입, 권한 확인 기능을 제공한다.

   - 과정, 회차, 수강 신청, 공지, 문의, 파일, 배너 데이터를 저장한다.

   - 이미지와 첨부 파일을 업로드하고 필요한 메뉴에 연결한다.

   - 사용자 웹과 관리자 웹에서 사용할 API를 제공한다.

## ◆ 사용자 유형

### ● 일반 방문자

학원 과정을 알아보는 사람이다. 과정 목록과 상세 내용을 확인하고, 필요하면 문의를 남긴다.

### ● 수강 신청자

특정 과정에 지원하려는 사람이다. 과정 상세 정보를 확인한 뒤 신청서를 작성하고 제출한다.

### ● 관리자

학원 내부 운영자다. 과정, 회차, 신청자, 공지, 문의, 회원 정보를 관리한다.

### ● 원장 및 의사결정자

전체 구축 범위와 운영 방향을 검토한다. 1차 구축에 포함할 기능과 후순위 기능을 결정한다.

## ◆ 사용자 웹 기능

### ● 메인 화면

   - 학원 대표 이미지 또는 배너를 보여준다.

   - 주요 과정으로 바로 이동할 수 있게 한다.

   - 최신 공지와 문의하기 진입 버튼을 제공한다.

   - 사용자가 처음 들어왔을 때 학원의 주요 정보를 빠르게 파악할 수 있게 한다.

### ● 과정 목록

   - 모집 중인 과정과 운영 중인 과정을 목록으로 보여준다.

   - 과정명, 요약, 대표 이미지, 모집 상태를 표시한다.

   - 사용자가 관심 있는 과정을 선택하면 과정 상세 화면으로 이동한다.

   - 필요 시 과정 검색이나 분류 필터를 추가할 수 있다.

### ● 과정 상세

   - 과정명, 과정 요약, 상세 설명, 대표 이미지를 보여준다.

   - 교육 기간, 교육 시간, 정원, 모집 상태를 보여준다.

   - 여러 회차가 있을 경우 회차별 정보를 구분해서 보여준다.

   - 신청 가능한 회차는 수강 신청으로 이어지게 한다.

### ● 수강 신청

   - 신청자 이름, 연락처, 이메일을 입력받는다.

   - 생년월일, 성별, 주소, 직업, 학력 등 신청에 필요한 정보를 입력받는다.

   - 지원 내용 또는 상담 요청 내용을 입력받는다.

   - 개인정보 수집 및 이용 동의를 받은 뒤 신청을 제출한다.

   - 제출된 신청 정보는 관리자 화면에서 확인할 수 있다.

### ● 공지사항

   - 학원 공지, 개강 안내, 준비물, 일정 변경 등을 게시한다.

   - 사용자는 공지 목록과 상세 내용을 확인한다.

   - 중요한 공지는 상단에 고정할 수 있다.

### ● 문의하기

   - 사용자가 이름, 연락처, 이메일, 제목, 내용을 입력해 문의를 남긴다.

   - 접수된 문의는 관리자 화면에서 확인하고 답변한다.

   - 문의 처리 상태는 대기, 처리 중, 완료 등으로 관리할 수 있다.

## ◆ 관리자 웹 기능

### ● 로그인 및 권한

   - 관리자는 아이디 또는 이메일과 비밀번호로 로그인한다.

   - 관리자 권한이 있는 계정만 관리자 메뉴에 접근할 수 있다.

   - 로그인 상태를 확인해 비인가 접근을 막는다.

### ● 과정 관리

   - 과정 목록을 조회한다.

   - 과정명, 요약, 상세 설명, 노출 여부, 상태, 정렬 순서를 등록한다.

   - 대표 이미지와 상세 이미지를 등록한다.

   - 과정 정보를 수정하거나 삭제 처리한다.

### ● 회차 관리

   - 과정별 기수 또는 회차를 등록한다.

   - 교육 시작일, 종료일, 교육 시작 시간, 종료 시간을 입력한다.

   - 정원과 모집 상태를 관리한다.

   - 회차별 신청 인원을 확인한다.

### ● 신청자 관리

   - 특정 과정과 회차에 신청한 사람을 확인한다.

   - 신청자의 기본 정보와 신청 상세 내용을 확인한다.

   - 신청 상태 또는 승인 상태를 관리한다.

   - 필요 시 관리자 메모를 남긴다.

### ● 공지사항 관리

   - 공지 목록을 조회한다.

   - 공지 제목, 내용, 작성자, 노출 여부를 등록한다.

   - 공지를 수정하거나 삭제한다.

   - 공지 이미지를 첨부한다.

   - 중요한 공지는 상단 고정으로 관리한다.

### ● 문의사항 관리

   - 문의 목록을 조회한다.

   - 문의 상세 내용을 확인한다.

   - 관리자 답변 또는 답글을 작성한다.

   - 문의 처리 상태를 변경한다.

   - 불필요한 문의는 삭제 처리한다.

### ● 회원 관리

   - 회원 목록을 검색하고 확인한다.

   - 회원 상세 정보를 확인한다.

   - 회원의 수강 신청 기록을 확인한다.

   - 회원 상태와 기본 정보를 수정한다.

   - 필요 시 비밀번호를 초기화한다.

### ● 파일 및 이미지 관리

   - 과정 이미지, 공지 이미지, 배너 이미지를 업로드한다.

   - 업로드된 파일은 과정, 공지, 배너 등 필요한 데이터에 연결한다.

   - 파일 저장 방식은 로컬 저장소 또는 Supabase Storage를 사용할 수 있다.

### ● 배너 관리

   - 메인 화면에 노출할 배너를 등록한다.

   - 배너 제목, 설명, 이미지, 링크를 관리한다.

   - 배너 노출 여부와 노출 기간을 설정한다.

   - 1차 구축 포함 여부는 검토가 필요하다.

## ◆ 주요 업무 흐름

### ● 과정 등록부터 신청까지

◇ 관리자가 과정 정보를 등록한다.

◇ 관리자가 과정 회차를 등록한다.

◇ 사용자가 과정 목록에서 과정을 선택한다.

◇ 사용자가 과정 상세에서 회차 정보를 확인한다.

◇ 사용자가 신청서를 작성하고 제출한다.

◇ 관리자가 회차별 신청자 목록에서 신청자를 확인한다.

◇ 관리자가 신청 상태와 메모를 관리한다.

### ● 공지 게시 흐름

◇ 관리자가 공지 제목과 내용을 작성한다.

◇ 필요한 경우 이미지를 첨부한다.

◇ 노출 여부와 상단 고정 여부를 선택한다.

◇ 사용자 웹 공지사항에 게시된다.

### ● 문의 처리 흐름

◇ 사용자가 문의를 등록한다.

◇ 관리자가 신규 문의를 확인한다.

◇ 관리자가 답변을 작성하거나 처리 상태를 변경한다.

◇ 문의 처리가 끝나면 완료 상태로 관리한다.

   - 페이지 제목과 과정 목록을 표시한다.

   - 각 과정은 이미지, 과정명, 요약, 모집 상태를 포함한다.

   - 상세 보기 또는 신청하기 버튼을 제공한다.

### ● 사용자 과정 상세 화면

   - 과정 대표 정보와 상세 설명을 표시한다.

   - 회차별 교육 기간, 시간, 정원, 모집 상태를 보여준다.

   - 신청 가능한 회차는 신청 버튼을 제공한다.

   - 참고 화면: D:\React\React_ITGwangju_Admin\storyboard\사용자_과정접수_과정상세.png

### ● 관리자 과정 관리 화면

   - 과정 등록/수정 화면에서 기본 정보와 이미지를 입력한다.

   - 과정 상세 화면에서 회차 등록과 신청자 확인을 제공한다.

## ◆ 데이터 구성

### ● 회원 데이터

로그인 계정, 이메일, 이름, 연락처, 상태, 권한 정보를 저장한다. 관리자와 일반 사용자를 구분할 수 있어야 한다.

### ● 과정 데이터

과정명, 요약, 상세 설명, 대표 이미지, 노출 여부, 상태, 정렬 순서를 저장한다.

### ● 과정 회차 데이터

과정별 기수, 교육 기간, 교육 시간, 정원, 모집 상태를 저장한다.

### ● 수강 신청 데이터

어떤 사용자가 어떤 과정과 회차에 신청했는지 저장한다. 신청 상태, 승인 상태, 신청 일시, 관리자 메모를 함께 저장한다.

### ● 신청 상세 데이터

신청서에 입력한 이름, 연락처, 이메일, 생년월일, 주소, 직업, 학력, 지원 내용을 저장한다.

### ● 공지사항 데이터

공지 제목, 내용, 작성자, 조회수, 노출 여부, 상단 고정 여부를 저장한다.

### ● 문의사항 데이터

문의자 정보, 문의 제목, 문의 내용, 답변, 처리 상태를 저장한다.

### ● 파일 데이터

업로드 파일의 원본명, 저장명, 저장 위치, URL, 용량, 업로드 정보를 저장한다.

### ● 배너 데이터

배너 제목, 부제목, 설명, 이미지, 링크, 노출 여부, 노출 기간을 저장한다.

## ◆ 1차 구축 우선순위

### ● 사용자 과정 목록, 상세, 신청

실제 모집과 가장 직접적으로 연결되는 기능이다. 사용자가 과정 정보를 보고 신청까지 완료할 수 있어야 한다.

### ● 관리자 과정, 회차, 신청자 관리

학원 운영자가 직접 과정 정보를 바꾸고 신청자를 확인할 수 있어야 한다.

### ● 공지사항

개강 안내, 준비물, 일정 변경 등 학원 운영 공지를 전달하기 위해 필요하다.

### ● 문의사항

방문자 상담 문의를 웹사이트에서 접수하고 관리하기 위해 필요하다.

### ● 회원 관리와 비밀번호 초기화

관리자 계정과 신청자 정보를 운영하기 위해 필요하다.

### ● 메인 배너

홍보성과 첫 화면 완성도를 높이기 위한 기능이다. 1차 구축 포함 여부는 별도 결정한다.

## ◆ 결정 필요 사항

### ● 회원가입 필수 여부

수강 신청을 비회원으로 받을지, 회원가입 후 신청하게 할지 결정해야 한다.

### ● 신청 처리 단계

신청 완료만 관리할지, 상담 중, 승인, 반려 같은 상태까지 관리할지 결정해야 한다.

### ● 마이페이지 필요 여부

신청자가 본인 신청 내역을 확인하는 화면이 필요한지 결정해야 한다.

### ● 과정 분류 방식

웹디자인, 영상편집, 컴퓨터활용능력 등 과정 카테고리를 고정할지 결정해야 한다.

### ● 문의 답변 확인 방식

답변을 관리자 내부 기록으로만 둘지, 사용자가 답변을 확인할 수 있게 할지 결정해야 한다.

### ● 문자 또는 메일 알림

신청 접수, 문의 답변, 개강 안내를 문자나 이메일로 자동 발송할지 결정해야 한다.

## ◆ 후순위 검토 항목

### ● 결제 기능

국비 과정 접수와 직접 관련이 낮아 1차 구축에서는 제외하는 것이 적절하다.

### ● 출결 관리

별도 행정 시스템과 중복될 수 있어 필요 여부를 먼저 확인해야 한다.

### ● 강사 전용 페이지

1차 모집 및 관리자 기능이 안정된 이후 검토하는 것이 적절하다.

### ● 자동 문자 발송

발송 서비스 계약, 비용, 개인정보 처리 기준 확인 후 검토한다.

### ● 통계 대시보드

초기에는 신청자 수와 과정 현황 중심으로 단순하게 시작하고, 이후 확장한다.

## ◆ 원장 검토용 요약

이번 웹사이트는 학원 과정 홍보와 수강 신청을 자체적으로 받기 위한 시스템이다.

사용자는 과정 정보를 보고 신청서를 제출한다.

관리자는 과정, 회차, 신청자, 공지, 문의, 회원 정보를 직접 관리한다.

1차 목표는 “과정 등록 → 사용자 신청 → 관리자 확인” 흐름을 안정적으로 완성하는 것이다.
