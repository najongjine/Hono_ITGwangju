# IT광주 학원 DB 구조 설명

기준 DB: .env.development / Neon PostgreSQL
갱신일: 2026-08-11

표기:
- NOT NULL: 필수 값
- NULL: 선택 값
- FK: 다른 테이블을 참조하는 외래키

============================================================

## t_user
로그인 계정과 회원 기본정보

- id: integer, NOT NULL, PK - 회원 식별자
- provider: varchar, NULL, 기본값 google - 가입 제공자(local, google 등)
- provider_user_id: varchar, NULL - 외부 로그인 제공자의 회원 식별자
- email: varchar, NULL, UNIQUE - 회원 이메일
- profile_image_url: varchar, NULL - 프로필 이미지 URL
- status: varchar, NULL, 기본값 active - active(사용), inactive(비활성)
- last_login_at: timestamp, NULL - 마지막 로그인 시각
- created_at: timestamp, NULL - 생성 시각
- updated_at: timestamp, NULL - 수정 시각
- username: varchar, NULL - 로그인 아이디
- password: varchar, NULL - 해시 처리된 비밀번호
- real_name: varchar, NULL - 암호화된 회원 실명
- phone: varchar, NULL - 암호화된 회원 연락처

## t_user_roles
회원별 권한

- id: integer, NOT NULL, PK - 회원 권한 식별자
- user_id: integer, NOT NULL, FK -> t_user.id - 권한을 가진 회원
- role_name: varchar, NULL - user(일반회원), staff(직원), admin(관리자)
- created_at: timestamp, NULL - 권한 부여 시각

## t_courses
학원 교육 과정 기본정보

- id: integer, NOT NULL, PK - 과정 식별자
- course_name: varchar, NOT NULL - 과정명
- summary: varchar, NULL - 과정 요약
- description: text, NULL - 과정 상세 설명
- thumbnail_file_id: integer, NULL, FK -> t_files.id - 대표 이미지
- is_visible: boolean, NULL, 기본값 true - 사용자 페이지 노출 여부
- status: varchar, NULL, 기본값 운영중 - 모집중, 운영중, 마감, deleted(삭제)
- sort_order: integer, NULL, 기본값 0 - 노출 순서, 작은 값 우선
- created_by: integer, NULL, FK -> t_user.id - 등록한 직원·관리자
- updated_by: integer, NULL, FK -> t_user.id - 마지막 수정 직원·관리자
- created_at: timestamp, NULL - 생성 시각
- updated_at: timestamp, NULL - 수정 시각

## t_course_sessions
교육 과정별 모집·운영 회차

- id: integer, NOT NULL, PK - 회차 식별자
- course_id: integer, NOT NULL, FK -> t_courses.id - 소속 과정
- session_name: varchar, NULL - 회차명 또는 기수명
- session_no: integer, NULL - 회차 번호
- start_date: date, NULL - 교육 시작일
- end_date: date, NULL - 교육 종료일
- capacity: integer, NULL, 기본값 20 - 모집 정원
- status: varchar, NULL, 기본값 모집중 - 모집중, 운영중, 마감, deleted(삭제)
- created_at: timestamp, NULL - 생성 시각
- updated_at: timestamp, NULL - 수정 시각
- class_start_time: time, NULL - 일일 수업 시작 시각
- class_end_time: time, NULL - 일일 수업 종료 시각

## t_enrollments
회원의 과정 회차 신청

- id: integer, NOT NULL, PK - 신청 식별자
- user_id: integer, NOT NULL, FK -> t_user.id - 신청 회원
- course_id: integer, NOT NULL, FK -> t_courses.id - 신청 과정
- session_id: integer, NOT NULL, FK -> t_course_sessions.id - 신청 회차
- memo: text, NULL - 직원·관리자 처리 메모
- applied_at: timestamp, NOT NULL - 신청 시각
- created_at: timestamp, NOT NULL - 생성 시각
- updated_at: timestamp, NOT NULL - 수정 시각
- status: varchar, NOT NULL, 기본값 pending - pending(승인대기), approved(승인), rejected(반려)

제약:
- 동일 회원은 동일 회차에 한 번만 신청 가능: UNIQUE(user_id, session_id)
- status는 pending, approved, rejected만 허용

## t_notices
학원 공지사항

- id: integer, NOT NULL, PK - 공지 식별자
- title: varchar, NOT NULL - 공지 제목
- content: text, NULL - 공지 내용
- author_id: integer, NULL, FK -> t_user.id - 작성 회원
- author_name: varchar, NULL - 작성 당시 표시용 작성자명
- view_count: integer, NULL, 기본값 0 - 조회 수
- is_visible: boolean, NULL, 기본값 true - 사용자 페이지 노출 여부
- is_pinned: boolean, NULL, 기본값 false - 목록 상단 고정 여부
- status: varchar, NULL, 기본값 published - published(게시), deleted(삭제)
- published_at: timestamp, NULL - 게시 시각
- created_at: timestamp, NOT NULL - 생성 시각
- updated_at: timestamp, NOT NULL - 수정 시각

## t_inquiries
로그인 회원이 작성한 문의 원문

- id: integer, NOT NULL, PK - 문의 식별자
- user_id: integer, NOT NULL, FK -> t_user.id - 작성 회원
- title: varchar, NULL - 문의 제목
- content: text, NULL - 문의 내용
- created_at: timestamp, NULL - 작성 시각
- updated_at: timestamp, NULL - 마지막 수정 또는 답글 작성 시각

연락처는 저장하지 않으며 user_id로 t_user에서 조회한다.

## t_inquiry_replies
문의에 작성된 사용자·직원 답글

- id: integer, NOT NULL, PK - 답글 식별자
- inquiry_id: integer, NOT NULL, FK -> t_inquiries.id - 원문 문의
- user_id: integer, NULL, FK -> t_user.id - 답글 작성 회원
- content: text, NOT NULL - 답글 내용
- created_at: timestamp, NOT NULL - 작성 시각
- updated_at: timestamp, NOT NULL - 수정 시각

작성자 역할은 user_id로 t_user_roles에서 조회한다.
문의 삭제 시 연결된 답글도 함께 삭제된다.

## t_files
업로드 파일 메타데이터

- id: integer, NOT NULL, PK - 파일 식별자
- original_name: varchar, NULL - 업로드 당시 원본 파일명
- stored_name: varchar, NULL - 저장소에 저장된 파일명
- file_path: varchar, NULL - 로컬 저장 파일 경로
- mime_type: varchar, NULL - MIME 유형
- file_size: bigint, NULL - 파일 크기(byte)
- created_at: timestamp, NULL - 업로드 시각
- storage_type: varchar, NULL, 기본값 local - local(서버), cloudinary(Cloudinary)
- bucket: varchar, NULL - 외부 저장소 버킷 또는 Cloudinary 클라우드명
- storage_key: varchar, NULL - 저장소 내부 파일 키
- public_url: varchar, NULL - 외부 공개 URL
- updated_at: timestamp, NOT NULL - 수정 시각
- uploaded_by: integer, NULL, FK -> t_user.id - 업로드 회원
- status: varchar, NOT NULL, 기본값 active - active(사용), deleted(삭제)

## t_file_links
파일과 과정·공지·배너 등 업무 데이터의 연결

- id: integer, NOT NULL, PK - 파일 연결 식별자
- file_id: integer, NOT NULL, FK -> t_files.id - 연결 파일
- target_table: varchar, NOT NULL - 대상 테이블명(t_courses, t_notices 등)
- target_id: integer, NOT NULL - 대상 데이터 식별자
- file_role: varchar, NULL, 기본값 attachment - attachment, description_image 등
- sort_order: integer, NULL, 기본값 0 - 표시 순서
- created_at: timestamp, NULL - 생성 시각
- updated_at: timestamp, NULL - 수정 시각

## t_banner
홈페이지 노출 배너

- id: integer, NOT NULL, PK - 배너 식별자
- title: varchar, NULL - 배너 제목
- subtitle: varchar, NULL - 배너 부제목
- description: text, NULL - 배너 설명
- image_file_id: integer, NULL, FK -> t_files.id - 배너 이미지
- link_url: varchar, NULL - 클릭 이동 URL
- link_target: varchar, NULL, 기본값 _self - _self(현재 창), _blank(새 창)
- position: varchar, NULL, 기본값 main - 배너 노출 위치
- is_visible: boolean, NULL, 기본값 true - 노출 여부
- status: varchar, NULL, 기본값 active - active(사용), deleted(삭제)
- sort_order: integer, NULL, 기본값 0 - 노출 순서
- start_at: timestamp, NULL - 노출 시작 시각
- end_at: timestamp, NULL - 노출 종료 시각
- created_by: integer, NULL, FK -> t_user.id - 등록한 직원·관리자
- updated_by: integer, NULL, FK -> t_user.id - 마지막 수정 직원·관리자
- created_at: timestamp, NULL - 생성 시각
- updated_at: timestamp, NULL - 수정 시각

## t_test1

- title: varchar, NULL - 테스트 제목
- content: varchar, NULL - 테스트 내용

## t_test1_child
개발용 테스트 자식 테이블

- comment: varchar, NULL - 테스트 댓글
- created_dt: timestamptz, NULL - 생성 시각
- test1_id: integer, NULL, FK -> t_test1.id - 부모 테스트 데이터

실제 DB 구조 확인 SQL:

SELECT
    c.table_name,
    obj_description(cls.oid, 'pg_class') AS table_comment,
    c.ordinal_position,
    c.column_name,
    c.data_type,
    c.is_nullable,
    c.column_default,
    col_description(cls.oid, c.ordinal_position) AS column_comment
FROM information_schema.columns c
JOIN pg_class cls ON cls.relname = c.table_name
JOIN pg_namespace n
  ON n.oid = cls.relnamespace
 AND n.nspname = c.table_schema
WHERE c.table_schema = 'public'
  AND cls.relkind = 'r'
ORDER BY c.table_name, c.ordinal_position;
